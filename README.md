# pyspatialuncertainty

Uncertainty of spatial averages and totals of maps. This package is a Python implementation of the Monte Carlo integration method of
Wadoux & Heuvelink (2023), *Uncertainty of spatial averages and totals of natural resource
maps*, Methods in Ecology and Evolution 14:1320–1332 ([doi:10.1111/2041-210X.14106](https://doi.org/10.1111/2041-210X.14106)).

Work in progress: see the documentation site and the report for details.
